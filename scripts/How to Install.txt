EasyCut — how to install

Requires an Apple Silicon Mac (M1 or later) with macOS 14 or later.

1. Drag EasyCut into the Applications folder in this window.
2. Open EasyCut from Applications.
3. The first time only, macOS may say it can't verify the developer
   (the app is not notarized). Go to System Settings › Privacy & Security
   and click "Open Anyway", then open EasyCut again.

Updates: from version 1.3.0 on, EasyCut tells you when a new version is out
and installs it with one click.

Speech recognition: click "Turn On Whisper" in the Transcript tab once to
download the Whisper model (about 574 MB). Apple's built-in engine works
without any download.

Source code and help: https://github.com/contenjoo/easycut
