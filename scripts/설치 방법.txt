EasyCut 설치 방법 (M1·M2·M3·M4 등 Apple Silicon Mac, macOS 14 이상)
===================================================================

1. 설치
   이 창의 EasyCut 아이콘을 옆의 "Applications(응용 프로그램)" 폴더로 끌어다 놓으세요.

2. 처음 열기 (한 번만)
   EasyCut은 App Store 밖에서 배포되는 앱이라 처음 열 때 macOS가 확인 창을 띄웁니다.
   ① 응용 프로그램 폴더에서 EasyCut을 더블클릭 → 경고 창이 뜨면 [완료]
   ② 시스템 설정 › 개인정보 보호 및 보안 → 아래쪽 "EasyCut이(가) 차단되었습니다" 옆 [그래도 열기]
   ③ 다시 EasyCut을 열고 [열기]를 누르면 끝. 다음부터는 바로 열립니다.

   (터미널이 익숙하다면 아래 한 줄로도 됩니다)
   xattr -dr com.apple.quarantine /Applications/EasyCut.app

3. 음성 인식 (자막·대본)
   · 기본: Mac 내장 음성 인식 — 처음 쓸 때 "음성 인식 허용" 창이 뜨면 [허용]
   · 더 정확하고 빠르게: 대본 탭의 [Whisper 켜기] 버튼 → 인식 모델(약 574MB)을 한 번만 받으면 끝

4. 유튜브 등 링크로 가져오기
   미디어 탭 [링크] → 처음 한 번 [유튜브 도구 설치] 버튼을 누르세요.
   본인 영상이나 이용 허락을 받은 영상만 받아 편집하세요.

5. Claude로 말해서 편집하기 (선택)
   AI 탭 → [Claude 연결 도우미] → ① Claude Code 설치 ② 로그인(Claude Pro/Max 계정) 순서대로 버튼만 누르면 됩니다.
   API 키가 있다면 AI 탭 ⚙︎ › 연결 방식 › API 키로도 쓸 수 있습니다.
   모델(Fable·Opus·Sonnet·Haiku)과 추론 강도는 AI 탭 위쪽에서 고를 수 있습니다.

단축키 목록은 앱에서 ⌘/ 를 누르면 볼 수 있습니다.
