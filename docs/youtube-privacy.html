EasyCut Studio의 YouTube 연동 개인정보처리방침

주식회사 오늘배움 · 2026년 11월 22일

오케이컷(EasyCut)의 Mac용 방송 스튜디오는 Google 로그인을 통해 본인의 YouTube 채널에 라이브 방송을 예약하고 송출할 수 있는 기능입니다. 이 안내는 방송 스튜디오에서 Google 계정을 연결할 때 적용됩니다.

어떤 정보를 왜 사용하는지

계정을 연결하면 앱은 YouTube Data API를 통해 사용자가 선택한 채널의 이름과 식별자를 확인합니다. 방송 예약에는 제목, 시작 예정 시각, 공개 범위와 아동용 콘텐츠 여부를 사용합니다. 앱은 선택한 예약의 송출 주소를 받아 방송을 시작하고 종료 상태를 확인합니다. Google 동의 화면에 표시되는 YouTube 계정 관리 권한은 이 작업을 수행하는 데 사용됩니다.

어디에 저장되고 누구에게 전송되는지

계정 연결을 유지하는 인증 정보는 해당 Mac 사용자의 키체인에 저장합니다. 앱은 채널과 이 Mac에서 만든 방송의 식별자를 로컬 설정에 보관해 다음에 예약을 불러옵니다. 송출용 키는 연결에 필요한 동안만 사용합니다.

예약 정보는 사용자의 Google 계정을 통해 YouTube로 전송됩니다. 라이브를 시작하면 선택한 화면과 소리가 해당 YouTube 채널로 전송됩니다. 방송 공개 범위는 사용자가 예약할 때 정하며 기본값은 비공개입니다. 녹화 원본과 편집 프로젝트는 Mac에 저장됩니다. 이 연동 기능은 Google 인증 정보나 방송 영상을 오늘배움 서버에 전송하지 않습니다.

연결 해제와 데이터 삭제

  • 오케이컷의 방송 스튜디오에서 실시간 송출 → YouTube 계정 → 방송 선택·예약 → 계정 연결 해제를 선택하면 앱이 키체인의 인증 정보를 제거하고 Google에 접근 권한 철회를 요청합니다. Google 계정의 서드 파티 연결 관리에서도 권한을 취소할 수 있습니다.
  • 이미 생성된 예약과 다시보기는 본인이 YouTube Studio에서 삭제할 수 있습니다. 로컬 녹화 원본과 편집 프로젝트는 Finder에서 삭제할 수 있습니다.
  • 이 Mac 사용자의 방송 식별자를 모두 지우려면 오케이컷을 종료한 뒤 터미널에서 defaults delete com.contenjoo.easycut YouTubeLiveService.createdBroadcastIDsByChannel을 실행하세요. 이 Mac의 앱 목록에서 기존 예약을 불러오는 연결이 사라집니다. 해당 예약은 YouTube Studio에서 계속 관리할 수 있습니다.
  • 이 기능의 데이터 처리에 관한 문의는 joo@learntoday.kr로 보내 주세요.

관련 약관과 정책

이 기능은 YouTube API 서비스를 사용합니다. YouTube 이용에는 YouTube 서비스 약관이 적용됩니다. Google이 정보를 처리하는 방법은 Google 개인정보처리방침에서 확인할 수 있습니다. 오케이컷은 Google API에서 받은 정보의 사용 및 다른 앱으로의 전송에 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 적용합니다.
