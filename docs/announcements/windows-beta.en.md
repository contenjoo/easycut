# 🎬 EasyCut for Windows (beta) is here!

[한국어](windows-beta.md) | **English**

EasyCut, the free video editor that used to be Mac-only, now runs on Windows too.
It turns your speech into a transcript, and when you delete words from the text, the video is cut to match.

## ✅ What works on Windows

- Import video, audio and images (drag and drop)
- Speech recognition (Whisper) → delete words in the transcript and the video is cut with them
- Remove filler words like "um" and "uh" in one go
- One-click silence cut: remove every pause at once
- Auto captions from the transcript + font, color and position styling, SRT import/export
- Multi-track timeline (split, move, trim, speed)
- MP4 export (with burned-in captions)
- Opens project files (.easycut) made on the Mac as they are
- Korean and English interface

## 💻 Install

- Windows 10/11 (64-bit)
- Open the link below, pick the top (latest) release, and run `EasyCut_…_x64-setup.exe` from its Assets
- The app is not signed yet, so if "Windows protected your PC" appears, click **[More info] → [Run anyway]**
- The speech recognition model (574 MB) downloads once, the first time you use it
