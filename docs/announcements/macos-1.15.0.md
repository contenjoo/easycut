# EasyCut 1.15.0 — 소리 다듬기와 단어 강조 자막

- **목소리 선명하게**: 클립 속성 **오디오**에서 켜면 에어컨·웅웅거림 같은 배경 소음을 줄입니다.
- **음량 자동 맞추기**: 내보내기 창 **소리**에서 유튜브·쇼츠 -14 / 강의 -16 / 방송 -23 LUFS를 고릅니다. 화면은 다시 인코딩하지 않습니다.
- **배경음악 자동 줄이기**: 대본이 있는 말소리가 나오는 동안 대본 없는 오디오(배경음악)를 약 12 dB 낮춥니다.
- **말하는 단어 강조 자막**: 쇼츠처럼 지금 말하는 단어만 강조색으로 바뀝니다. 대본이 없으면 글자 수로 나눕니다.
- AI 편집에서 말로도 켤 수 있습니다. Windows 0.9.0에도 같은 기능이 있습니다(Windows는 소음 줄이기를 내보낼 때 적용).

## English

EasyCut 1.15.0 adds sound polish: per-clip noise reduction, loudness normalization on export (-14/-16/-23 LUFS) and automatic ducking of background music under transcribed speech. Captions can now highlight the spoken word, Shorts style. Windows 0.9.0 offers the same features.
