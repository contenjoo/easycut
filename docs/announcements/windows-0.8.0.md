# EasyCut for Windows 0.8.0 — 폰트·효과·전환을 한눈에

소재, 큰 미리보기와 타임라인, 선택 항목의 설정을 세 영역으로 정리했습니다. 오른쪽 **기본 / 효과 / 배치** 탭에서 설정하고, 이름과 아이콘이 있는 카드로 효과를 선택하세요.

- 시작·끝에 각각 고르는 **전환 18종**, 타이핑·바운스 등을 포함한 **텍스트 효과 15종**, 강도를 조절하는 **색감 필터 9종**.
- PC에 **설치된 전체 폰트 검색·미리보기**와 한글 별칭 검색.
- 효과 카드 위에 고정된 시간·강도·효과 재생 버튼. 자주 쓰는 작업은 도구막대, 나머지는 **더 보기**에서 실행합니다.
- 효과를 프로젝트에 저장하고 MP4 내보내기에 반영합니다. 기존 프로젝트와 실행 취소·다시 실행을 지원합니다.
- Mac 1.14.0과 같은 효과 식별자를 사용합니다. 운영체제별 렌더러 차이로 세부 모양은 조금 다를 수 있습니다.

Windows에서 설치·Whisper·MCP·영상 생성·실제 WebView2 폰트/효과 선택과 MP4 출력을 확인한 설치 파일입니다.

[Windows 0.8.0 내려받기](https://github.com/contenjoo/easycut/releases/download/win-v0.8.0/EasyCut_0.8.0_x64-setup.exe) · [Mac 1.14.0 내려받기](https://github.com/contenjoo/easycut/releases/download/v1.14.0/EasyCut-1.14.0.dmg)

## English

Windows 0.8.0 adds a simpler three-pane editor with pinned **Basic / Effects / Layout** tabs, 18 entrance/exit transitions, 15 text animations and 9 adjustable visual looks. Search and preview all fonts installed on your PC, including Korean aliases. Effects persist in projects and render in MP4 exports. The installer, speech transcription, video creation and native WebView2 editing flow were verified on Windows.
