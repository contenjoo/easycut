# 🎬 EasyCut 윈도우 버전(베타)이 나왔습니다!

**한국어** | [English](windows-beta.en.md)

맥에서만 되던 무료 영상 편집기 EasyCut을 이제 윈도우에서도 쓸 수 있어요.
말한 내용을 글로 바꿔서, 글을 지우면 영상도 같이 잘리는 편집기입니다.

## ✅ 윈도우에서 되는 것

- 영상·오디오·사진 가져오기 (끌어다 놓기)
- 음성 인식(Whisper) → 대본에서 필요 없는 말을 지우면 영상도 같이 삭제
- "음", "어" 같은 군더더기 한 번에 제거
- 원클릭 무음 컷: 말 없는 구간을 한 번에 잘라내기
- 대본으로 자막 자동 생성 + 글꼴·색·위치 꾸미기, SRT 가져오기/내보내기
- 멀티 트랙 타임라인 (분할·이동·트림·속도 조절)
- MP4 내보내기 (자막 입히기 포함)
- 맥에서 만든 프로젝트 파일(.easycut)을 그대로 열 수 있어요

## 💻 설치

- Windows 10/11 (64비트)
- 아래 링크 맨 위(최신) 버전의 Assets에서 `EasyCut_…_x64-setup.exe`를 받아 실행
- 서명되지 않은 앱이라 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**
- 음성 인식 모델(574MB)은 처음 한 번만 받으면 돼요
