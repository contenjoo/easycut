# 오케이컷 for Windows 0.10.0 — EasyCut의 새 이름

EasyCut for Windows가 **오케이컷(OK Cut)**으로 이름을 바꿨습니다.

- 창 제목, 시작 메뉴·바탕화면 바로가기, '앱 및 기능' 목록, 아이콘이 OK Cut으로 표시됩니다.
- 앱 안 업데이트로 그대로 이어집니다. 설치 폴더, 프로젝트 파일(.easycut), 설정, AI 연결, MCP 도구 이름(`easycut`)은 바꾸지 않았습니다.

[Windows 0.10.0 내려받기](https://github.com/contenjoo/easycut/releases/download/win-v0.10.0/OKCut_0.10.0_x64-setup.exe) · [Mac 1.16.0 내려받기](https://github.com/contenjoo/easycut/releases/download/v1.16.0/OKCut-1.16.0.dmg)

## English

EasyCut for Windows is now **OK Cut**. The window title, shortcuts, Apps & features entry and icon use the new name; updating keeps your install folder, projects, settings and MCP tool name.
