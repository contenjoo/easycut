# 오케이컷 1.16.0 — EasyCut의 새 이름

EasyCut이 **오케이컷(OK Cut)**으로 이름을 바꿨습니다. 촬영장의 "오케이, 컷!"처럼 한국어로도 영어로도 바로 통하는 이름입니다.

- Finder·Dock·메뉴 막대·아이콘에 새 이름이 보입니다. 영어 환경에서는 **OK Cut**으로 표시됩니다.
- 쓰던 앱은 업데이트만 하면 그대로 이어집니다. 프로젝트 파일(.easycut), 설정, API 키, 화면 녹화·카메라 권한, 녹화·다운로드 폴더는 그대로입니다.
- Claude·Codex에 연결한 MCP 도구 이름(`easycut`)과 앱 경로(`/Applications/EasyCut.app`)도 그대로라 다시 연결하지 않아도 됩니다.
- Windows 0.10.0도 함께 이름을 바꿨습니다. 시작 메뉴·바탕화면 바로가기와 '앱 및 기능' 목록에 OK Cut으로 보입니다.

[Mac 1.16.0 내려받기](https://github.com/contenjoo/easycut/releases/download/v1.16.0/OKCut-1.16.0.dmg) · [Windows 0.10.0 내려받기](https://github.com/contenjoo/easycut/releases/download/win-v0.10.0/OKCut_0.10.0_x64-setup.exe)

## English

EasyCut is now **OK Cut** (오케이컷). Existing installs update in place and keep their projects (.easycut), settings, API keys, permissions and the MCP tool name (`easycut`). Windows 0.10.0 carries the same new name.
