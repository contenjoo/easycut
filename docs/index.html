타임라인처럼 정리한 기능

트랙 색은 앱 안의 클립 색과 같습니다. 파란색은 영상, 초록색은 소리, 보라색은 자막입니다.

편집

대본으로 편집

대본에서 말을 골라 ⌫를 누르면 그 말이 영상에서 잘리고 뒤가 당겨집니다.

원클릭 무음 컷

음성 인식 없이 소리 크기만으로 말 없는 구간을 찾아 한 번에 지웁니다.

최대 20배속

미리보기는 0.25~20배속, 클립 속도는 0.1~20배까지 음정을 유지한 채 바꿉니다.

소리

음성 인식

Whisper가 앱 안에 들어 있어 인터넷 없이 한국어·영어 등 7개 언어를 받아씁니다.

군더더기 제거

'음', '어', '그' 같은 말을 대본에서 찾아 한꺼번에 지웁니다.

화면·얼굴 녹화

화면, 카메라, 마이크, 컴퓨터 소리를 함께 녹화하고 끝나면 트랙에 나눠 배치합니다.

자막

자동 자막

대본으로 자막을 만들고, SRT로 가져오거나 내보내고, 영상에 입힙니다.

자막으로 컷 편집

자막 한 줄을 지우면 그 구간 영상도 지워지고, 순서를 바꾸면 영상도 따라 움직입니다.

자막 시간 맞추기

자막마다 실제 말이 시작되는 순간을 소리로 재서 빠르거나 늦은 자막을 맞춥니다.

화면

개인정보 가리기

화면 글자를 읽어 전화번호·주민번호·이메일이 보이는 자리와 시간만 흐리게 가립니다.

화면 배치

화면 속 화면, 원 모양 얼굴 카메라, 인물 배경 흐리기, 마우스 클릭 강조를 넣습니다.

내보내기

MP4(H.264·HEVC), ProRes, 소리만(M4A), 4K부터 480p까지, 장면 PNG 저장.

설명으로 새 영상 만들기

Mac·Windows 상단의 영상 만들기에서 시작하세요. 주제·줄거리·스타일·글자·소리를 자유롭게 설명하면 애니메이션·설명·홍보 영상을 만듭니다. 특정 장소나 스타일에 고정되지 않습니다.

만드는 순서

1. AI를 고르고 설명하기

Claude·GPT·Gemini 중에서 고르고 원하는 내용·화면비·길이를 입력합니다. Claude와 GPT는 구독 로그인 또는 API 키로, Gemini는 API 키로 연결합니다.

2. 미리보기 4장 확인

설명으로 미리보기 만들기를 누릅니다. 구도·색상·문구와 장면 변화를 확인하고, 적용한 제작 지침과 원본도 볼 수 있습니다.

3. 영상으로 만들고 편집

확인하고 전체 렌더링으로 MP4를 만듭니다. 타임라인에 추가해 자막·음성·음악을 더하고 편집을 이어 갑니다.

스킬 자동 적용

설명에 맞는 지침만

제품·브랜드 모션, 개념 설명, 움직이는 타이포, 데이터 이야기, 입자·패턴 아트 등 5개 스킬 중 필요한 지침을 최대 3개 골라 적용합니다.

요청한 표현이 우선

차분하게, 글자 없이, 무음으로 같은 조건을 우선합니다. 자동 적용을 끄고 설명만으로 만들 수도 있습니다.

원본과 선택 이유 확인

미리보기와 함께 어떤 지침을 왜 골랐는지 보여 줍니다. 검토한 스킬을 현재 제작 방식에 맞게 적용합니다.

영상 제작 품질을 우선한다면 현재 Claude Opus 5.5를 가장 권장합니다. Claude와 GPT는 본인 구독 계정이나 API 키로 사용할 수 있고, Gemini는 API 키로 연결합니다. 구독 연결에는 해당 계정의 사용 한도가 적용되며, API 요금은 구독과 별도입니다. 키는 사용자의 Mac 키체인 또는 Windows 자격 증명 관리자에 저장합니다.

새 영상 만들기는 macOS 1.13.0·Windows 0.7.0부터 제공합니다. 두 운영체제 모두 미리보기 4장 확인, 제작 스킬 자동 적용, 전체 렌더링과 타임라인 추가를 지원합니다. English guide

시작하기 전에

새 영상 만들기는 AI가 작성한 장면 코드를 사용자의 컴퓨터에서 렌더링합니다. 기본 편집과 필요한 준비가 다릅니다.

AI는 어떻게 연결하나요?

영상 만들기에서 AI를 고른 뒤 연결 방식을 선택합니다. Claude와 GPT는 본인 구독 계정으로 로그인하거나 본인의 API 키를 저장합니다. GPT 구독은 ChatGPT 계정으로 로그인합니다. Gemini는 현재 API 키로 연결합니다. 앱의 API 키 발급 안내에서 공식 안내를 열 수 있습니다. API 사용료는 별도입니다.

추가로 무엇이 필요한가요?

영상 생성에는 Node.js LTS·npm과 Google Chrome(Windows에서는 Edge도 가능)이 필요합니다. 렌더링 패키지는 처음 한 번 앱 전용 폴더에 준비합니다. 고급 설정에서 Canvas 또는 Remotion을 선택할 수 있습니다.

길이와 소리도 정할 수 있나요?

한 번에 2~60초, 24·30·60fps를 지원합니다. Canvas에서는 음악·효과음을 코드로 합성하거나 무음으로 만듭니다. Remotion의 기본 생성물은 무음입니다. 내레이션 음성은 생성하지 않으며 타임라인에서 추가할 수 있습니다.

어떤 정보가 AI에 전송되나요?

입력한 영상 설명을 선택한 AI 공급자에 전송합니다. 생성 코드는 사용자의 컴퓨터에서 실행하고 원본 영상 전체를 업로드하지 않습니다. 사용자가 확인한 코드와 설정으로 전체 영상을 렌더링합니다.

설치

기본 편집은 무료이고 소스가 공개되어 있습니다(MIT). 기존 사용자는 앱의 업데이트 확인으로 새 버전을 받을 수 있습니다. AI 계정·API 사용료는 별도입니다.
