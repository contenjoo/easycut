설치 방법

DMG를 열어 EasyCut을 응용 프로그램 폴더로 옮기세요. 처음 실행할 때 macOS가 확인을 요구하면 시스템 설정의 개인정보 보호 및 보안에서 앱 이름을 확인하세요.

녹화를 30초 단위로 저장해 앱이 갑자기 꺼져도 다음 실행 때 복구합니다. 1시간 녹화도 정지 후 약 20초면 파일 하나로 완성됩니다.

시작하기 전에

방송 키 없이 YouTube에 연결할 수 있나요?

방송 스튜디오에서 Google 계정으로 본인의 YouTube 채널에 연결하세요. 라이브 스트리밍이 활성화된 채널에서 바로 송출하거나 비공개로 예약할 수 있습니다. Google 권한 심사 중에는 신규 계정 연결이 제한될 수 있습니다.

운영체제별 계정 연결 방법 ↗
AI 영상 만들기에는 무엇이 필요한가요?

Node.js LTS와 npm, Chrome(Windows는 Edge도 지원)이 필요합니다. Claude와 GPT는 구독 로그인 또는 본인의 API 키, Gemini는 API 키를 연결하세요. 입력한 설명은 선택한 공급자로 전송되고 영상은 내 컴퓨터에서 렌더링됩니다.

자막과 완성 영상은 어떤 형식으로 저장하나요?

대본으로 자막을 만들거나 SRT 자막을 가져올 수 있습니다. 편집을 마친 영상은 MP4로 내보내고 자막은 SRT 파일로도 저장할 수 있습니다.
