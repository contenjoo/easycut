EasyCut 방송 스튜디오

EasyCut 방송 스튜디오에서는 내 Google 계정으로 로그인해 YouTube 채널에 방송을 예약하고 송출합니다. 녹화가 끝나면 방송 중 바꾼 장면이 편집 타임라인에 열립니다.

내 배치 만들기

내 배치 편집에서 화면 또는 카메라를 선택하고 끌어서 위치를 옮깁니다. 모서리 손잡이로 크기를 바꿉니다. 두 소스가 겹치면 위에 놓을 소스를 선택하고 맨 앞으로를 누른 뒤 적용하세요. 이 기기에 저장한 구성은 내 배치 장면으로 다시 선택할 수 있습니다. 방송 중 배치를 수정하면 적용한 시점이 편집 타임라인에 기록됩니다.

Mac에서 예약하고 방송하기

  1. 방송 스튜디오 위쪽의 방송 일정을 엽니다. 처음 연결할 때는 Google로 연결을 누르고 방송할 YouTube 채널의 계정을 선택합니다.
  2. 연결된 채널 이름을 확인한 뒤 새 방송에서 제목, 예정 시각, 공개 범위와 아동용 여부를 지정합니다. 처음 만드는 방송은 비공개가 기본입니다.
  3. 방송할 때는 입력 장치에서 화면·카메라·소리를 고르고, 장면 썸네일을 눌러 시작 배치를 확인합니다. 송출 설정에서 실시간 송출 → YouTube 계정을 켜고 사용할 예약을 선택한 뒤 녹화 및 라이브 시작을 누릅니다.
  4. 방송 중에는 모니터 아래에서 장면을 바꿉니다. 정지를 누르면 편집기에 장면별 클립이 열립니다.

Windows에서 예약하고 방송하기

Windows용 방송 스튜디오는 EasyCut 0.11.0부터 제공됩니다.

  1. 편집기에서 방송 스튜디오를 엽니다. 송출 설정 → 목적지에서 YouTube Live를 고르고 Google 계정으로 연결을 누릅니다. 기본 브라우저에서 채널을 선택한 뒤 EasyCut에 표시된 채널 이름을 확인하세요.
  2. 방송 선택 → 새 방송 예약에서 제목과 현지 시작 시각, 공개 범위, 아동용 여부를 정한 뒤 YouTube에 예약을 누릅니다. 기본 공개 범위는 비공개입니다.
  3. 방송할 때는 예약한 방송 사용에서 예약을 고릅니다. 바로 시작하려면 지금 방송을 선택하고 방송 정보를 입력하세요. 입력 장치에서 카메라와 소리를 고른 뒤 화면 선택·미리보기에서 공유할 화면과 첫 장면을 확인하고 녹화와 송출을 시작합니다.
  4. 방송 중에는 미리보기 아래에서 장면을 전환합니다. 종료하고 편집을 누르면 화면과 카메라가 장면별 클립으로 타임라인에 들어옵니다.

본인 채널에서 YouTube 라이브 스트리밍을 사용할 수 있어야 합니다. 현재 기기의 예약 목록에는 이 기기에서 해당 채널로 예약한 방송이 표시됩니다. 다른 기기에서 만든 예약까지 보려면 YouTube Studio를 여세요.
