# 효과 선택·편집 UI 개편 검증 (macOS, 2026-11-02)

## 변경 내용

- 왼쪽 작업 공간, 가운데 큰 미리보기, 오른쪽 선택 항목 설정으로 화면 비중 조정. 도구막대 주요 작업은 아이콘과 이름을 함께 표시하고 분할·삭제는 타임라인에 배치했다.
- 오른쪽에 선택 항목의 이름·시간과 **기본 / 효과 / 배치** 탭을 고정했다. 시간·강도와 효과 재생 버튼은 카드 목록 위에 배치했다.
- 전환 18종, 텍스트 등장 15종, 영상·사진 색감 필터 9종을 이름·아이콘·선택 표시가 있는 카드로 선택한다. 전환은 클립 시작·끝에 독립적으로 적용한다.
- 글꼴은 설치된 전체 계열을 실제 PostScript 이름과 연결해 검색한다. 한글 글꼴 샘플과 추천을 제공하며 나눔·산돌·주아·한나·프리텐다드 등 한글 검색 별칭을 지원한다.
- 이름으로 선택한 글꼴의 굵게 켜기·끄기가 실제 글꼴 변형에 반영되도록 수정했다.
- 속도·오디오·모양·인물 배경·개인정보 가리기·페이드·자막 시간 조절은 해당 기본/효과/배치 탭에서 제공한다.
- 미리보기는 최신 합성을 기다린 뒤 재생하고, 그사이 선택 항목이 바뀌면 이전 항목을 재생하지 않는다. 전체 자막 효과 재생은 클립 선택 여부와 관계없이 자막 시작을 사용한다.
- 기존 프로젝트를 여는 optional 저장 형식, 실행 취소·다시 실행, 공통 미리보기·내보내기 경로를 유지했다. 필터는 개인정보를 가린 이미지에만 적용한다.

## 자동 검사

- Debug/Release 빌드 통과.
- 효과 검사 **205개** 통과: 전환·텍스트 효과 전체 픽셀과 변환 좌표, 필터9종·강도0 원본 일치, 저장 호환성·분할·합치기, AI 입력 검증·취소, 글꼴·굵게·검색, 미리보기 선택 변경·자막 시작 회귀 검사 포함.
- 이 Mac의 설치 글꼴 **378개 계열**을 실제 렌더링 가능한 이름으로 목록에 수록함을 확인했다. 개수는 Mac마다 다르다.
- 생성 이미지·제목·자막으로 실제 3초 320×180 H.264 MP4를 출력했다. 원형 열기·카드 뒤집기·빈티지65%·바운스 제목·선명해지는 자막을 포함한다.
- 5시점 미리보기 대비 MP4 평균 RGB 오차는 0.001~0.031(0~1)로 기준0.035 이내.
- 기존 타임라인 검사 **33개** 통과. 제품 코드 변경과 관련 없는 기존 배속 검사를 반복하지 않았다.

## 실제 앱 확인

- 설치 앱에서 새 도구막대와 고정 기본/효과/배치 탭, 전환·텍스트·필터 카드와 선택 표시를 확인했다.
- 전환을 원형 열기에서 페이드로 변경하고 필터를 빈티지에서 흑백으로 변경, 강도65%→60% 조절, 효과 재생 동작을 확인했다.
- 도구막대에서 텍스트를 추가하고 글꼴 검색창에서 Nanum 검색→5개 결과→Nanum Gothic 적용, 텍스트 효과 통통 튀기 선택을 확인했다.
- 한글 ‘나눔’ 검색이 영문 Nanum을 찾지 못하는 문제를 발견해 별칭을 추가하고 자동 검사에 포함했다. 최종 설치 화면에서도 ‘나눔’ 검색으로 5개 결과가 표시됨을 확인했다.
- 전체 창과 더 작은 창에서 도구 이름·재생 도구·3열 카드·상단 조절 영역을 시각 검증했다. 카드가 많은 경우 목록은 세로 스크롤을 사용한다.
- 검증은 새로 생성한 임시 프로젝트만 사용했다. 기존 사용자 프로젝트를 수정하지 않았다.

## 재현

```sh
swift build -c debug
EASYCUT_SELFTEST_ONLY=effects .build/debug/EasyCut --selftest /private/tmp/easycut-studio-final-20261102
EASYCUT_SELFTEST_ONLY=natural .build/debug/EasyCut --selftest /private/tmp/easycut-studio-regression
./scripts/relaunch.sh /private/tmp/easycut-studio-final-20261102/effects.easycut
./scripts/build_app.sh --dmg
```

로그: `/private/tmp/easycut-studio-effects-final.log`, `/private/tmp/easycut-studio-timeline.log`, `/private/tmp/easycut-studio-final-package.log`.

설치 전 앱은 `dist/EasyCut-before-studio-20261102.app.zip`으로 보관했다. 최종 설치 위치는 `/Applications/EasyCut.app`, 배포용 보관물은 `dist/EasyCut.app.zip`과 `dist/EasyCut-1.13.0.dmg`다. 공개 릴리스·Windows UI 변경은 수행하지 않았다.
