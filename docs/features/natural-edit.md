# 말하면서 편집 · 파일명 편집 (첫 버전)

Mac과 Windows 상단의 **말·파일명 편집**에서 사용합니다. 기존 AI 계정 연결이 필요합니다.

## 말하면서 편집

녹화 설정에서 **말하면서 편집 (녹화 후 지시 검토)**를 켜고 마이크를 켭니다.
녹화 중 `편집아, 여기 확대해줘.`처럼 한 문장으로 말하고 잠깐 쉽니다.
녹화가 끝나면 기존 음성 인식 경로로 대본을 만들고 검토 창을 엽니다.
기존 영상도 음성 인식 후 상단 버튼으로 지시를 읽을 수 있습니다.

호출어가 있는 지시만 후보로 표시하며, 한국어 지시 종결어 / 문장 끝 / 0.55초 쉼 / 클립 경계 / 최대 8초에서 끝납니다.
실제 발화와 인식이 다르면 지시 선택을 해제하세요. 호출어만 있는 구간은 제외합니다.
목록에서 적용할 지시를 고른 뒤 **AI로 초안 만들기**를 누릅니다.
지시 구간 제거와 기존 편집 도구 적용은 AI가 수행합니다. 시간 범위가 모호한 삭제는 확인하도록 지시합니다.

## 파일명으로 편집

클립을 고른 뒤 상단 버튼을 누르면 미디어 파일명을 불러옵니다.
`강의_말줄이고_3분.mp4`처럼 첫 밑줄 뒤를 요청으로 읽습니다.
검토 창에서 주문용 이름만 바꿔도 됩니다. 디스크의 원본 이름과 파일은 변경하지 않습니다.
**파일명에서 편집 요청 읽기**를 켜고 해석된 요청을 확인한 뒤 적용합니다.
일반 파일명은 요청으로 취급하지 않습니다. 탐색기/Finder의 이름 변경을 자동 감시하지 않습니다.

## 복원과 범위

AI 적용 직전 프로젝트를 메모리에 보관하며 **초안 이전 복원**으로 여러 편집을 한 번에 되돌립니다.
복원도 실행 취소할 수 있습니다. 앱 종료·프로젝트 전환 시 이 임시 사본은 유지되지 않으므로 프로젝트 파일도 저장하세요.
원본 미디어는 덮어쓰지 않습니다. 새 초안 실행 시 이전 임시 사본은 교체됩니다.

이 버전은 녹화 후 대본 기반 편집입니다. 실시간 스트리밍 편집·자동 내보내기·실제 파일명 감시는 포함하지 않습니다.
현재 AI 도구가 지원하지 않는 효과는 적용되지 않으며 AI 결과에서 미적용 내용을 확인해야 합니다.
