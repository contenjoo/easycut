EasyCut for Windows 0.8.0 (검증 중 / validation build)

[새 기능] 폰트·효과·전환 선택
• 오른쪽 [기본 / 효과 / 배치]에서 필요한 설정을 한눈에 확인합니다. 효과 카드에 이름·아이콘·선택 표시를 넣고, 시간·강도·효과 재생을 위에 고정했습니다.
• 시작·끝 전환 18종, 텍스트 등장 효과 15종, 색감 필터 9종을 선택합니다. 타이핑·팝업·통통 튀기·흔들기·원형 열기·카드 뒤집기 등을 지원합니다.
• PC에 설치된 전체 글꼴을 검색하고 미리 봅니다. 한글 별칭 검색을 지원하며, 조회 실패 시 다시 시도할 수 있습니다.
• 미디어·미리보기·타임라인·속성을 세 영역으로 정리하고, 드물게 쓰는 도구는 [더 보기]에 모았습니다.
• 효과는 프로젝트에 저장되며 미리보기와 영상 내보내기에 적용됩니다. Mac과 같은 효과 식별자를 사용하되 렌더러 차이로 세부 모양은 다를 수 있습니다.

[New] Fonts, effects and a simpler editor
• Pinned Basic / Effects / Layout tabs, named effect cards and visible duration, intensity and replay controls.
• Choose 18 entrance/exit transitions, 15 text animations and 9 adjustable visual looks.
• Search and preview the fonts installed on your PC, including Korean family aliases.
• Effects persist in projects and render in MP4 exports. Mac and Windows use the same effect identifiers; rendering details can differ.

[새 기능] 설명으로 영상 만들기
• 상단 [영상 만들기], 파일 메뉴 또는 AI 탭에서 시작합니다. 주제·줄거리·스타일·움직임·글자·소리를 자유롭게 설명하세요.
• Claude와 GPT는 본인 구독 계정 로그인 또는 API 키로, Gemini는 API 키로 연결합니다. GPT 구독은 ChatGPT 계정을 사용합니다.
• 구독 계정에는 해당 계정의 사용 한도가 적용됩니다. API 사용료는 구독 요금과 별도이며, API 키는 Windows 자격 증명 관리자에 저장합니다.
• EasyCut의 영상 제작 권장 모델은 Claude Opus 5.5입니다. API 모델명은 직접 바꿀 수 있습니다.

[새 기능] 제작 스킬 자동 적용
• 제품·브랜드 모션, 개념 설명, 움직이는 타이포, 데이터 이야기, 입자·패턴 아트 등 검토된 5개 스킬에서 설명에 맞는 지침을 최대 3개 선택합니다.
• 요청한 스타일과 내용이 우선하며 자동 적용을 끌 수 있습니다. 적용한 스킬·선택 이유·원본 링크를 미리보기와 함께 확인합니다.

[제작 순서] 미리보기 확인 후 렌더링
• 미리보기 4장을 확인한 뒤 [확인하고 전체 렌더링]으로 MP4를 만듭니다. 코드나 설정이 바뀌면 미리보기를 다시 생성해야 합니다.
• 완성 영상을 재생하거나 폴더에서 보고 타임라인에 추가합니다. 창을 닫아도 작업은 계속되며 [중지]로 취소합니다.
• 2~60초, 24·30·60fps와 가로·세로·정사각형 화면을 지원합니다. Canvas는 음악·효과음을 코드로 합성할 수 있고 Remotion 기본 출력은 무음입니다. 내레이션 음성은 생성하지 않습니다.
• 영상 생성에는 Node.js LTS·npm과 Chrome 또는 Edge가 필요합니다. 렌더링 패키지는 처음 한 번 앱 전용 폴더에 준비합니다.

[New] Create videos from a prompt
• Start from the toolbar, File menu or AI tab. Describe your own animation, explainer or promotional video.
• Use your own Claude/ChatGPT subscription sign-in or Claude/OpenAI API key. Gemini connects with an API key.
• Subscription limits apply to the signed-in account. API usage is billed separately; keys are stored in Windows Credential Manager. EasyCut currently recommends Claude Opus 5.5 for video creation quality.
• Automatic guidance selects up to three relevant skills from five reviewed production skills, respecting your brief. Review the selected skills, reasons and source links, or turn the feature off.
• Review four sample frames before approving the full MP4 render. Code/settings changes require new previews. Play the result, open its folder or add it to the timeline. Closing the window keeps work running; Stop cancels it.
• Supports 2–60 seconds, 24/30/60 fps, and landscape/portrait/square presets. Canvas supports synthesized music/effects; Remotion output is silent by default. Narration is not generated.
• Prepare Node.js LTS, npm and Chrome or Edge. Rendering packages are installed in the app's support folder on first use.
